# Security reports

Do not post access tokens, refresh tokens, one-time authorization codes, or personal account data in public issues. Use GitHub's private vulnerability reporting if enabled; otherwise contact the maintainer privately before sharing sensitive details.

This is an early release. The launcher downloads and installs code and content from your Epic/Fab account. Review changes affecting authentication, archive paths, symlinks, verification, and file removal carefully. The repository contains a public Epic OAuth client identifier/credential used for interoperability, not a user session or private developer API key.

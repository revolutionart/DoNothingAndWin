# Launcher workspace

The launcher manages Unreal Engine installations, projects and plugins, and updates its own installed edition.

## Language

**Launcher update**:
Replacement of the installed DoNothing&Win application with a newer release. It is distinct from an Unreal Engine or plugin update.

**Plugin update catalogue**:
The accepted plugin version comparisons for each engine installation. A plugin can be current in one engine installation and need an update in another.

**Engine installation**:
A particular installed copy of Unreal Engine at a filesystem location, identified by its version and association.

**Engine operation**:
An installation, verification, removal or change to the selected contents of an engine installation.

**Prepared engine installation**:
A selected engine release with verified installation information, a destination and a choice of contents. Preparation does not mean the engine has been installed.

**Resume entry**:
A retained prepared engine installation that can be started again after an interrupted transfer. Dismissing the entry does not delete downloaded files.
